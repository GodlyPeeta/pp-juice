# pp-juice
Discord bot mainly used for osu commands and for using nitro emotes with a non-nitro account. 

## Use:
Edit config.py to whatever you need  
Delete everything that is obviously not manually added from the database in the db folder (a few items in the tables that were added by hand need to be kept)  
Add a file to lib folder called proudsimp.mp4 because dumb windows wouldn't copy it  
Run bot.py
